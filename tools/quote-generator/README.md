# 报价表生成器（quote-gen）

根据客户清单（SKU + 数量）自动生成正式报价单 xlsx。是官网"报价表导出"在线功能的原型工具。

## 用法

```bash
# 1. 把客户清单存成文本文件（每行一条：SKU 空格/逗号/制表符 数量）
echo "ZQS-1440 1
MSP-S01 2" > 清单.txt

# 2. 生成报价表
python3 quote_gen.py 清单.txt -o 报价表-2026-09-02.xlsx -d 2026-09-02
```

- 依赖：`pip install openpyxl`
- SKU 自动匹配：支持带连字符/去连字符两种写法（ZQS-1440 = ZQS1440），变体 SKU 自动带变体价
- 价格规则：有 P1 价格的产品自动填价并算小计；无价产品价格列留空（客户会来询价）
- 输出：正式格式（公司抬头、报价日期、有效期 7 天、WhatsApp、合计行、备注）
